# Task 11 – Phishing Simulation and Awareness

## Overview
This task demonstrates a controlled phishing simulation conducted for
educational and cybersecurity awareness purposes. The objective is to
understand how phishing attacks are designed, how users are targeted, and
how such attacks can be identified and prevented.

The activity was performed in a safe, ethical, and isolated environment
using dummy data only. No real credentials, users, or external systems
were involved.

## Tools and Environment
- Operating System: Windows 11
- Tools Used:
  - Web Browser
  - HTML
  - Notepad / Text Editor

## Objectives
- Understand phishing attack structure
- Create a simulated phishing email
- Design a fake login (landing) page
- Analyze common phishing indicators
- Document preventive security measures

## Methodology
1. Created a phishing email template using HTML.
2. Designed a fake login page to simulate credential harvesting.
3. Simulated sending the phishing email to self only.
4. Observed user interaction behavior.
5. Documented phishing indicators and prevention techniques.
6. Collected screenshots as evidence.

## Files Included
- `analysis.txt` – Technical observations and security analysis
- `report.md` – Detailed phishing simulation report
- `email-template/` – Phishing email HTML file
- `landing-page/` – Fake login page HTML file
- `screenshots/` – Screenshots of all steps performed

## Outcome
This task provided hands-on understanding of phishing techniques and
highlighted the importance of user awareness, email verification, and
security best practices to prevent social engineering attacks.
